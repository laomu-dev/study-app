# 传输通信知识学习助手

一个面向传输通信知识复习的学习系统，支持用户登录、题库管理、每日复习任务和学习进度统计。

## 技术栈

- React + TypeScript + Vite
- Tailwind CSS
- Express API
- MySQL

## 本地开发

```bash
npm install
npm run dev
```

前端默认使用 `/api` 访问后端；生产环境可通过 `VITE_API_URL` 指定后端地址。

## 常用命令

```bash
npm run build
npm run check
npm run lint
```
